**Title:** Publishub: verify AI-generated code before it reaches production

**What it is**
Publishub is a verification tool for software built with AI coding agents. After a change, it runs your app's key user journeys in a real browser, catches regressions, and gives you evidence of what broke: the failing step, a screenshot and a bug report.

**Why I'm building it**
Agents like Claude Code, Cursor and Codex made writing code dramatically faster. Verifying it didn't get faster. The agent reports success, the tests pass, and a real flow is broken because the change touched something nobody asked it to. Today the fix is clicking through the app after every change, which cancels out much of the speed you gained.

**Who it helps**
Indie hackers, SaaS founders, AI-first developers and small teams who ship quickly without a dedicated QA team.
